# Day 22 — Compare up to three roles

Choose up to three unique roles from Explore or details, including across Explore pages. The fourth unselected comparison button is disabled until a selection is removed. Compare roles displays facts side by side on desktop and stacked on mobile. Refresh comparison fetches each selected ID from the API. Removed or unavailable listings keep their previous snapshot with an explicit warning. Selection snapshots are not automatically live data. Remove/Clear affects comparison only, not tracked applications. Selections clear on browser reload.

Install this batch once using the combined updater in DAY25.md. Do not create or install nine separate releases.
