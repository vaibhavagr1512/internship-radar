# Day 19 — Deadline and verification notices

Details and comparison explain missing, invalid, today and past deadlines. A past deadline is a prompt to check the source, not a definitive statement that applications are closed. Verification dates older than 30 calendar days, invalid dates and future dates are marked. Device-local today and date-only calendar comparisons avoid timezone shifts. Demo labels stay visible and do not imply real verified opportunities.

Install this batch once using the combined updater in DAY25.md. Do not create or install nine separate releases.
