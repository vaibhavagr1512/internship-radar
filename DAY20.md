# Day 20 — Save from details

The detail view uses the same useApplications hook as Explore, the dashboard and the tracker. Save internship to tracker is disabled while loading, during writes, on tracker failure and for an already-tracked listing. Already-tracked roles show their current status and a shortcut to My applications. Saving still does not submit an application to an employer; the existing API enforces duplicate rejection.

Install this batch once using the combined updater in DAY25.md. Do not create or install nine separate releases.
